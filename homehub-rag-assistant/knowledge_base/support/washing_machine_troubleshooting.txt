WASHING MACHINE TROUBLESHOOTING GUIDE

Problem: Washing machine does not start

Check that:
1. The appliance is connected to a suitable power source.
2. The door is completely closed.
3. The water supply is available.
4. The selected program has been started correctly.

Problem: Machine vibrates excessively

Check that:
1. The washing machine is positioned on a stable surface.
2. The machine is properly leveled.
3. The laundry load is distributed reasonably.
4. Shipping or transit bolts have been removed when required.

Problem: Water is not draining

Check the drain hose for visible blockage or incorrect positioning.
If the issue continues, contact authorized service support.

Customers should not disassemble electrical or mechanical components
unless specifically instructed by qualified service personnel.
